Automated Donor/Stakeholder Reporting System

Automated the creation of donor reports by integrating Monday.com project updates with OneDrive Excel data, delivering scheduled, customized reports through Azure. Reduced manual reporting time and improved donor transparency.

Technologies: Python | OneDrive | Monday.com API | Azure

Project Story ▶

Problem

The reporting process was chaotic and slow. Communications had to collect data manually from multiple sources — coordinators, fundraising, and finance — just to compile a single donor report.

Context

Teams often disagreed about which clients, families, or interventions were funded by which donor. A single automated system was needed to extract updates, merge them with financial and donor data, and produce ready-to-send reports.

Action

  • Designed a Python pipeline connecting to Monday.com's API to fetch tasks.
  • Downloaded subitems, cleaned and merged them into a predefined report template using python-docx.
  • Automated email delivery via Gmail SMTP and centralized reports in one repository.

Result

Donor reports that took 3–5 days are now generated in under 10 minutes, eliminating inconsistencies and missed updates.
